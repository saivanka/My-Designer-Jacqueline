# My-Designer-Jacqueline

A single-page splash site for “My Designer Jacqueline”. The whole site is one file, `index.html`: it shows an animated preloader spinner, then a button linking to the designer's bio page, and after a few seconds it opens the visitor's messaging app with a prefilled greeting so they can get in touch.

## Tech stack

- Plain HTML + inline CSS and JavaScript (no build step, no dependencies beyond CDN assets)
- Bootstrap 5.3.3 and Bootstrap Icons via CDN for styling and the button

## How to view

Open `index.html` in a browser, or visit the deployed site linked from the repository's About section (my-designer-jacqueline.vercel.app).

## Project structure

```
index.html   # The entire site: preloader animation, bio-page button, messaging prompt
```
